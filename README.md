# CEE Tender Intelligence v4

Готовий багатокористувацький MVP для команди KAM.

## Реалізовано
- кілька KAM у веб-панелі;
- призначення одного чи кількох ринків;
- індивідуальні ключові слова та мінімальна сума;
- вибір Telegram, email або обох каналів;
- мова дайджесту UA/PL;
- робочий дайджест о 09:00 Пн-Пт;
- відслідковування тендерів, статус, дата нагадування, нотатка;
- Excel-експорт;
- робочий конектор Prozorro;
- реєстр майбутніх конекторів TED, e-Zamówienia, SEAP, NEN, CVP IS, EIS, Riigihanked та UVO.

## Важливе обмеження
У цій версії автоматично завантажує дані тільки конектор Prozorro. Інші ринки показані в адмініструванні, але потребують окремої реалізації та, залежно від джерела, API-ключа або формальної інтеграції. Система не симулює дані з непідключених джерел.

## Запуск
1. Встановіть Docker Desktop.
2. Скопіюйте `.env.example` у `.env` і заповніть Telegram/SMTP.
3. Виконайте `docker compose up -d --build`.
4. Відкрийте `http://localhost:8000`.
5. Для Telegram: у картці KAM знайдіть ID і надішліть боту `/start ID`, наприклад `/start 1`.

## Email
Для email потрібні SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD і SMTP_FROM. Можна використати корпоративний SMTP relay або окрему поштову скриньку, дозволену політиками організації.

## Production
Перед зовнішнім розгортанням потрібно додати HTTPS, автентифікацію/SSO, резервне копіювання, журнал аудиту та керування секретами.
